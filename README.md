# Classy Creepers for LiquidBounce

A client add-on that gives creepers the original [Classy Creepers](https://github.com/CCBlueX/classy-creepers) top hat and monocle.

## Screenshots

![screenshot](/gh_assets/screenshot.png)

## Usage

1. Install this addon with the command provided above.
2. Locate the `ClassyCreepers` module in the `Fun` category and enable it.
3. Enjoy!
